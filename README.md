# WSR Notes

WSR Notes - веб-сайт для публикации и просмотра статей.

## Функционал

* регистрация и авторизация пользователей;
* вход и выход из аккаунта;
* создание статей;
* просмотр списка статей;
* просмотр отдельной статьи;
* редактирование и удаление статей;
* проверка владельца статьи;
* Django permissions для управления доступом;
* профиль пользователя;
* изменение username и email;
* изменение информации профиля;
* загрузка аватара;
* удаление аккаунта;
* адаптивный интерфейс для мобильных устройств.

## Стек

### Backend

* Python
* Django
* Django ORM
* Django Authentication
* Django Permissions

### Database

* SQLite

### Frontend

* HTML
* Tailwind CSS
* Django Templates

## Архитектура

Проект построен как классическое Django-монолитное приложение.

В проекте используются Django Models, Forms, Class-Based Views, Authentication, Permissions и Templates.

Особое внимание уделено разграничению доступа. Например, автор может изменять и удалять свои статьи, а пользователи с соответствующими Django permissions могут управлять статьями независимо от их владельца.
